# Jaffle Shop

This project loads customer and order source tables, stages those records,
loads raw payment rows as a dbt seed, and builds customer- and order-level
analytics models. It is based on the dbt Labs DuckDB Jaffle Shop project at
commit `36bde6cba69d962b83be1d52fc65a0dce1cb4ebb`.
